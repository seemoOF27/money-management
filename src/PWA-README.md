# إدارة الأموال الشخصية - Progressive Web App (PWA)

## ✨ الميزات

تطبيق ويب متقدم لإدارة الأموال الشخصية مع دعم PWA كامل:

### 🎯 الوظائف الرئيسية
- ✅ إدارة الميزانيات مع نظام Tags للتصنيف
- ✅ إدارة الديون (دائن/مدين) مع سدادات جزئية
- ✅ إدارة الاستثمارات وصندوق الطوارئ
- ✅ سجل العمليات الكامل
- ✅ نظام الفواتير الثابتة الدورية

### 📱 ميزات PWA
- ✅ يعمل بدون اتصال (Offline Support)
- ✅ قابل للتثبيت على الهاتف/الكمبيوتر
- ✅ تجربة تطبيق أصلي
- ✅ سرعة عالية مع التخزين المؤقت
- ✅ دعم كامل للغة العربية (RTL)
- ✅ تصميم متجاوب للجوال

### 🎨 التصميم
- لوغو احترافي مخصص
- أيقونات SVG قابلة للتحجيم
- ألوان متناسقة (أخضر زمردي)
- واجهة سهلة الاستخدام

## 🚀 كيفية التثبيت

### على الجوال (Android/iOS):
1. افتح الموقع في المتصفح
2. سيظهر banner التثبيت تلقائياً
3. اضغط على "تثبيت الآن"
4. أو من قائمة المتصفح: "إضافة إلى الشاشة الرئيسية"

### على الكمبيوتر (Chrome/Edge):
1. افتح الموقع
2. اضغط على أيقونة التثبيت في شريط العنوان (➕)
3. أو اضغط Ctrl+Shift+A ثم "تثبيت"

## 🔧 الملفات المهمة

```
/public/
  ├── manifest.json       # بيانات التطبيق
  ├── service-worker.js   # Service Worker للعمل بدون اتصال
  └── app-icon.svg        # اللوغو/الأيقونة

/components/
  └── Logo.tsx            # مكون اللوغو

/index.html               # ملف HTML الرئيسي مع PWA meta tags
```

## 🎨 اللوغو

اللوغو يحتوي على:
- محفظة مع عملات ذهبية
- رمز الريال السعودي (ر.س)
- تدرج لوني أخضر زمردي
- متاح بصيغة SVG لجميع الأحجام

## 🔐 الأمان

- المصادقة عبر Supabase
- تخزين آمن للبيانات
- Service Worker مع HTTPS فقط
